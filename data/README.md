# Data

All datasets are **public and free** (per thesis approval doc), so the project
stays open-source and reproducible. Raw videos and intermediate artifacts live
in `raw/` and `processed/` (gitignored — do not commit large files).

## Planned datasets

| Dataset | Use | Link | License |
|---------|-----|------|---------|
| COCO (person keypoints) | Pre-training / joint detection baseline | https://cocodataset.org/#keypoints-2017 | CC BY 4.0 |
| PoseTrack21 | Multi-person pose tracking, re-ID evaluation | https://posetrack.net/ | CC BY-NC-SA 4.0 |
| Human3.6M | 3D pose / keypoint ground truth | http://vision.imar.ro/human3.6m/ | Research-only (registration required) |
